# Single Source of Truth: Enforcement Protocol

**The LaTeX manuscript in `Paper/` is the authoritative source for ALL content.** Everything else is derived.

## The SSOT Chain

```
Paper/main.tex + Paper/sections/*.tex (SOURCE OF TRUTH)
  ├── Figures/ (derived from R scripts or TikZ source)
  ├── Tables/ (derived from R scripts)
  ├── Bibliography_base.bib (shared)
  └── output/*.rds (intermediate analysis results)

NEVER edit derived artifacts independently.
ALWAYS propagate changes from source → derived.
```

---

## Figure Freshness Protocol

**Before including any figure in the manuscript, verify it reflects the current analysis.**

1. Check that the R script producing the figure has not been modified since last output
2. If the script has changed, re-run it before compiling
3. Verify figure dimensions and format (PDF for LaTeX inclusion)

---

## Table Consistency

**Tables in `Tables/` are generated by R scripts, not hand-edited.**

1. Each .tex table file should have a comment header noting which script generated it
2. If regression specifications change, regenerate all affected tables
3. Verify table numbers and cross-references match the manuscript

---

## Content Fidelity Checklist

```
[ ] All \input{} paths resolve correctly
[ ] Every \cite{} key exists in Bibliography_base.bib
[ ] Every figure file referenced by \includegraphics exists
[ ] Every table file referenced by \input exists
[ ] No orphaned figures/tables (generated but not referenced)
[ ] Cross-references (\ref, \label) all resolve
```
