# LaTeX Formatting (House Style)

The formatting conventions for papers and slide decks in this workflow. The
paper conventions are implemented in `Preambles/header.tex` and the deck
conventions in `Preambles/beamer-header.tex`. `Slides/example_talk.tex` is a
worked example of every deck layout. This file governs mechanics. Prose style is
governed by the writing rules in this folder.

---

## Papers

### Engine, class and fonts
- **XeLaTeX**, with `fontspec` and `\setmainfont{Times New Roman}`.
- `\documentclass[12pt,letterpaper]{article}` with one-inch margins,
  `\usepackage[margin=1in]{geometry}`.

### Spacing
- Body text is set at 1.5 line spacing with `\setstretch{1.5}` from `setspace`.
  Use `\setstretch{1.5}` and avoid `\onehalfspacing`, which gives about 1.24 at
  12pt.
- The abstract is single-spaced. Wrap it in `\begin{spacing}{1} … \end{spacing}`.
- Footnotes hang flush with the margin, `\usepackage[hang,flushmargin]{footmisc}`.

### Citations and bibliography
- `\usepackage[authoryear,round]{natbib}` with `\bibliographystyle{aer}`.
- `\citet{}` when the work is the grammatical subject or object, `\citep{}` for
  parenthetical support.
- A paper with long appendices may give them a separate reference list through
  `multibib`. The three lines are in `header.tex`, commented out. Appendix
  citations then use `\citetapp` and `\citepapp`, and the compile pipeline gains
  a `bibtex app` step.

### Tables
- `booktabs` rules (`\toprule`, `\midrule`, `\bottomrule`) and no vertical lines.
  `tabularx`, `multirow` and `array` are loaded. Floats may use `[H]` from `float`.
- Captions are small with a bold label and a hanging indent,
  `\captionsetup{font=small,labelfont=bf,format=hang}`.
- Tables are generated by scripts. Each generated `.tex` table carries a comment
  header naming the script that produced it. Regenerate a table to change it.
  Never hand-edit one.

### Figures
- Figures are script output saved as PDF and included with
  `\includegraphics[width=\textwidth]{../Figures/...}`.
- Standard dimensions are 6.5 by 4 inches for a full-width figure and 6.5 by 3.2
  inches for a two-panel figure.
- Use a colorblind-safe palette and hold it fixed across the paper.

### Notation
- Define one macro per recurring symbol in `header.tex`, so that notation is
  consistent and can be changed in one edit. `\E` and `\Var` are defined.
- Theorem-like environments are `hypothesis`, `proposition` and `prediction`.

### Links
- `hyperref` with muted link colors, `blue!60!black` for links, citations and URLs.

### Numbers
- Thousands take a thin separator, `1{,}884`.
- Numeric and date ranges take an en dash, `1450--1650`.

### Compile pipeline
```bash
cd Paper
TEXINPUTS=../Preambles:$TEXINPUTS xelatex -interaction=nonstopmode main.tex
BIBINPUTS=..:$BIBINPUTS bibtex main
TEXINPUTS=../Preambles:$TEXINPUTS xelatex -interaction=nonstopmode main.tex
TEXINPUTS=../Preambles:$TEXINPUTS xelatex -interaction=nonstopmode main.tex
```
Verify zero `!` errors, no undefined references or citations, and no overfull
hbox above 10pt.

## Slide decks

### Class and theme
- `\documentclass[9pt]{beamer}`, 4:3, `\usetheme{default}` and
  `\usecolortheme{default}`. White background, no colored header bar and no
  footline. Navigation symbols are off.
- Add `aspectratio=169` for widescreen and raise the font to 10pt or 11pt if a
  room needs it. Add the class option `t` for a long course deck so content is
  top-aligned.

### Layout
- Figures carry most of the argument. `\figframe{Title}{graphic}{caption}` gives
  one figure a titled frame and `\fullfigframe{graphic}{caption}` gives it the
  whole slide.
- A frame that pairs an image with text uses `columns[T,onlytextwidth]`, with
  the image column near 38 percent of the text width.
- Captions and source lines are `\scriptsize` and gray. `\source{...}` sets a
  source line. The "Figure:" prefix is removed.
- An empty `\item[]` adds vertical space between bullets.
- Tables follow the paper rules, with `booktabs` and no vertical lines.

### Emphasis
- `\term{...}` sets a key term in bold muted blue, `blue!70!black`.
- `\alert{...}` sets a warning in bold muted red, `red!70!black`.
- `\muted{...}` sets secondary text in gray.
- Emphasis is done with these text colors. The `keybox` environment exists for
  the single takeaway of a frame. Use at most one box on a frame, and on few
  frames.

### Title frame and sections
- `\titleframe{Title}{Authors}{Venue and date}{email}` builds the title frame,
  which is centered and carries a "This Version" date.
- Each `\section{...}` produces a plain divider frame with the section title.

### Frame titles
- A frame title is a plain noun phrase naming the topic or a complete sentence
  stating the finding. See `no-implied-predicate-titles.md`.

### Compile
```bash
cd Slides
xelatex -interaction=nonstopmode deck.tex
```
Run `BIBINPUTS=..:$BIBINPUTS bibtex deck` and two more passes if the deck cites.
